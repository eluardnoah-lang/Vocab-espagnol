# ¡Vocabulario! – Espagnol

Application web pour apprendre 150 mots d'espagnol de base (cartes mémoire, quiz dans les deux sens, répétition espacée, progression sauvegardée).

Ouvrez simplement `index.html` dans Safari sur iPad (astuce : « Partager → Sur l'écran d'accueil » pour l'utiliser comme une app).
