# ¡Español! B2

Application web (un seul fichier `index.html`, sans installation) pour travailler l'espagnol niveau B2 :

- **Grammaire & temps** (phrases à trous + explication de la règle) : subjonctif présent, temps du passé, hypothèse et condition, concordance des temps et style indirect, ser/estar, por/para.
- **Connecteurs logiques, expressions idiomatiques, périphrases et verbes clés**, avec une phrase d'exemple pour chacun.
- Cartes mémoire, quiz à choix multiples (espagnol → français, français → espagnol, grammaire, mélangé).
- Répétition espacée : les erreurs reviennent plus souvent. Progression sauvegardée dans le navigateur.

Ouvrez `index.html` dans Safari sur iPad (astuce : « Partager → Sur l'écran d'accueil » pour l'utiliser comme une app).
